# CodeAlpha - Language Translation Tool (AI Task 1)

## 📌 Overview
An AI-powered interactive Language Translation Tool built with Python using the `googletrans` API and `ipywidgets`.

## 🚀 Features
- Auto-detection of source languages
- Supports 100+ target languages
- Interactive notebook interface

## 🛠️ Tech Stack
- Python 3
- Googletrans API
- Google Colab / Jupyter Notebooks
